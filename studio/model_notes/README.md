# Model Notes

This directory stores public-safe notes about model behavior and parameter tuning.

Use it for:

- model strengths and weak spots
- recommended samplers, steps, CFG/guidance, sizes, and clip skip
- hardware/runtime notes
- import compatibility notes
- non-private workflow observations

Do not store:

- generated images
- raw API responses
- private prompts
- personal or sensitive case archives
- files copied from model cards without permission

Private notes can live under `local_studio/model_notes/`, which is ignored by Git.

## Files

- `template.md`: Copy this when adding notes for a new model.
- `index.md`: Public index of model notes in this repository.
